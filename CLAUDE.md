## What this is

A GitHub Pages user site (`sarimansari.github.io`), served directly from the `main` branch with no build step. The entire site is currently a single static file, `index.html`, containing a placeholder "coming soon" landing page (inline CSS, no JS, no external assets or dependencies).

There is no build, lint, or test tooling in this repo — it's plain HTML/CSS. Edit `index.html` directly and open it in a browser to preview. Pushing to `main` republishes the live site at `https://sarimansari.github.io` automatically via GitHub Pages.
